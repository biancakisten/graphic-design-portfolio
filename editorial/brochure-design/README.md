# Promotional Brochure Design

## Project Overview

This project showcases a promotional brochure designed to communicate information in an engaging, visually organised format. The design focuses on presenting content clearly while maintaining a consistent visual style.

## Project Objectives

- Create an attractive promotional layout.
- Organise information using a clear visual hierarchy.
- Apply typography, spacing and alignment consistently.
- Use imagery and graphic elements to support the message.

## Design Tools

- Adobe InDesign
- Adobe Illustrator

## Design Process

The project involved arranging text and visual elements into a cohesive brochure layout, with attention to readability, composition and the overall promotional message.
