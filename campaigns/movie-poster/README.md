# Fictional Movie Poster Design

## Project Overview

This project explores the visual design of a poster for a fictional movie. The concept focuses on using imagery, typography, colour and composition to establish a cinematic mood and communicate the film's imagined identity.

## Project Objectives

- Develop a distinctive visual direction for a fictional film.
- Use composition and imagery to create atmosphere.
- Establish a strong typographic hierarchy.
- Combine visual elements into a cohesive poster design.

## Design Tools

- Adobe Photoshop

## Design Process

The poster was developed as a creative exercise in cinematic visual communication. The design explores how imagery, lighting, colour and typography can work together to suggest a story and capture an audience's attention.
