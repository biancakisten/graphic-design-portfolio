# Flyer Design

## Project Overview

This practice project explores promotional flyer design, focusing on communicating a message through an effective combination of typography, imagery and graphic elements.

## Project Objectives

- Create an attention-grabbing composition.
- Establish a clear visual hierarchy.
- Organise information for quick reading.
- Use colour, typography and imagery to support the message.

## Design Tools

- Adobe InDesign
- Adobe Photoshop

## Design Process

The project explores the relationship between visual impact and information hierarchy, with the aim of producing a flyer that is both engaging and easy to understand.
