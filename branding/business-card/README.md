# Business Card Design

## Project Overview

This project explores business card design for a fictional brand. The aim is to create a professional, memorable identity through considered typography, layout and visual consistency.

## Project Objectives

- Establish a clear and balanced layout.
- Present contact information in a readable format.
- Develop a cohesive visual identity for a fictional brand.
- Consider how the design translates to a printed format.

## Design Tools

- Adobe Illustrator
- Adobe InDesign

## Design Process

The design focuses on arranging brand elements and essential information into a compact format while maintaining visual clarity and consistency.
